This Excel workbook is part of my Manufacturing Operations & Performance Analytics portfolio project.

It contains the simulated manufacturing dataset, data cleaning and quality checks, KPI calculations, and Excel analysis using PivotTables to investigate production performance, product quality, downtime, material usage, and recorded production costs.

The goal was to prepare the data, identify key findings, and answer the project questions introduced in Phase 1.

**Tools used:** Microsoft Excel

**Note:** This project uses simulated data for educational and portfolio purposes. It does not represent Nestlé Ghana's internal data or actual manufacturing performance.
